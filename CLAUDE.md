# Puppy Chow

Monthly dog-behavior newsletter for San Diego shelter trainers, published to GitHub Pages from `docs/`.

- To produce an issue, follow `RUNBOOK.md` exactly.
- `docs/` is the public site: `docs/index.html` lists issues, `docs/YYYY-MM/index.html` is each issue.
- `planning/` holds the original plan; it isn't published.
- Personal project. Don't mix in anything from Reviewer3.
